# זמן אמת

אתר שסורק אתרי חדשות ישראליים דרך RSS, מזהה אירועים שמסוקרים ביותר ממקור אחד ומציג כל אירוע ככרטיס. הזיהוי הסמנטי רץ מקומית, בלי מפתחות API ובלי עלות שוטפת. האתר מציג כותרות וקישורים בלבד ולא מעתיק כתבות.

## התקנה

צריך Node.js בגרסה 20 ומעלה.

```bash
cd israel-news
npm install
```

בהרצה הראשונה המודל `multilingual-e5-small` (כ-130MB) יורד פעם אחת לתיקייה `models/`. מאותו רגע הוא רץ בלי אינטרנט.

## הרצה

```bash
npm start
```

פותחים את http://localhost:3000. הסריקה הראשונה מתחילה מיד ולוקחת כחצי דקה. הדף מתעדכן לבד כל 30 שניות.

- `npm test`: בדיקות יחידה, וגם בדיקות סמנטיות על כותרות אמיתיות מהפידים.
- `npm run eval`: דוח דיוק מלא של זיהוי האירועים (עם `VERBOSE=1` הוא מפרט כל טעות).
- `http://localhost:3000/#/status`: מצב כל מקור, כולל שגיאות.

## ריצה קבועה בענן (GitHub, בחינם)

כך האתר מתעדכן כל הזמן, גם כשהמחשב כבוי:

- **`.github/workflows/scan.yml`**: ריצה אחת ארוכה (כ-5.5 שעות) שסורקת כל 3 דקות (`scripts/scan-loop.js`) ומפרסמת אחרי כל סריקה. בסופה היא מפעילה בעצמה את הריצה הבאה. ה-cron של GitHub הוא רק גיבוי, כי הוא לא אמין. המצב נשמר בענף `data`: אירועים, ETag, וקבצי `events.json` ו-`status.json`.
- **`.github/workflows/pages.yml`**: מפרסם את `public/` ל-GitHub Pages. בכל פתיחה הדף קורא את `events.json` העדכני מהענף `data`.

הגדרה חד-פעמית:
1. מעלים את הפרויקט ל-repository **ציבורי** ב-GitHub. ב-repository ציבורי, Actions בחינם ובלי הגבלה.
2. ב-GitHub: **Settings → Pages → Source: GitHub Actions**.
3. ב-**Actions**: מריצים ידנית את "סריקת חדשות" פעם אחת (Run workflow). מאותו רגע הוא רץ לבד.

הערות:
- ההפרש בין ריצות ארוכות הוא אפסי כי הריצה הבאה מופעלת מיד בסוף הקודמת. אם משהו נכשל, הגיבוי השעתי מפעיל מחדש.
- אם אין שום פעילות ב-repository במשך 60 יום, GitHub משבית את הריצה המתוזמנת ושולח מייל. מפעילים אותה מחדש בלחיצה אחת בלשונית Actions.
- `npm start` עדיין עובד מקומית כמו קודם, לפיתוח.

## הגדרות (`config.json`)

כל ההגדרות נמצאות בקובץ אחד. אחרי שינוי מפעילים את השרת מחדש.

| הגדרה | ברירת מחדל | משמעות |
|---|---|---|
| `minSources` | `2` | כמה **מקורות שונים** צריכים לסקר סיפור כדי שייחשב אירוע. שתי כתבות מאותו אתר לא נחשבות. |
| `similarityThreshold` | `0.89` | מאיזה דמיון (0 עד 1) שתי כותרות בעברית נחשבות אותו אירוע. ערך גבוה יותר נותן פחות מיזוגים שגויים, וגם יותר פספוסים. |
| `crossLanguageThreshold` | `0.84` | אותו דבר, לזוג כותרות בעברית ובאנגלית (Jerusalem Post). |
| `scanIntervalMinutes` | `10` | כל כמה דקות סורקים. |
| `maxEvents` | `10` | כמה אירועים מוצגים לכל היותר. |
| `eventMergeThreshold` | `0.875` | אירועים שכבר קיימים מתאחדים אם הדמיון הממוצע ביניהם עובר את הערך הזה, ולפחות זוג כותרות אחד עובר את `similarityThreshold`. זה מונע כרטיסים כפולים על אותו סיפור. |
| `noSharedNamePenalty` | `0.01` | שתי כותרות בעברית בלי אף מילה נדירה משותפת (שם, חברה, מקום) צריכות להיות דומות יותר בערך הזה כדי להתאחד. מונע איחוד של סיפורים שרק נשמעים דומים. |
| `storyMergeThreshold` | `0.865` | שני אירועים שיש להם מילת מפתח משותפת (מילה שמופיעה בלפחות שתיים ומחצית מהכותרות של כל אחד, למשל "פליי דובאי") מתאחדים כבר מדמיון ממוצע כזה. מאחד זוויות שונות של אותה פרשה. `0` מכבה. |
| `showPhotos` | `false` | הצגת תמונות מהפידים של האתרים. כבוי בכוונה: צילומי עיתונות מוגנים בזכויות יוצרים ולרוב מורשים לאתר עצמו בלבד. להדליק רק אחרי אישור בכתב מהאתרים. |
| `singleSourceFallbackMinutes` | `10` | אם במשך כך וכך דקות לא זוהה אירוע ממספר מקורות, נוסף הסיפור "החם" ביותר ממקור אחד, מסומן "חם · מקור אחד". כשאתר נוסף מסקר אותו, הוא הופך לאירוע רגיל. `0` מכבה. |
| `articleMaxAgeHours` | `24` | כתבות ישנות יותר מזה לא נכנסות לזיהוי. |

### העלאת מספר המקורות המינימלי ל-3

כשיתווספו מקורות, משנים ב-`config.json`:

```json
"minSources": 3,
```

ומפעילים מחדש (`npm start`). אירועים שכבר זוהו נשארים, והחדשים יצטרכו 3 מקורות.

### כיוון סף הדמיון

כדי לבדוק ערך בלי לשנות את הקובץ:

```bash
THRESHOLD=0.88 npm run eval
```

מה בודקים בפלט: "different-event kept apart" (כמה מיזוגים שגויים נמנעו) מול "same-event found" (כמה התאמות נכונות נמצאו).

## הוספת מקור חדש

1. מאמתים שיש לאתר פיד RSS רשמי ועדכני, ושה-`robots.txt` לא אוסר עליו.
2. מוסיפים רשומה לרשימה `sources` ב-`config.json`:

```json
{
  "id": "newsite",
  "name": "שם האתר",
  "color": "#8a2be2",
  "enabled": true,
  "feeds": ["https://example.co.il/rss.xml"],
  "includeUrlPatterns": ["example\\.co\\.il/news/"],
  "excludeUrlPatterns": ["/opinion/"],
  "excludeTitlePatterns": ["ממומן"],
  "dateLabelIsLocalTime": false
}
```

- `feeds`: אפשר לתת כמה פידים, והם ייחשבו מקור אחד (כמו אצל גלובס).
- `breakingFeeds`: פיד המבזקים של האתר, אם יש לו. כתבה משם נחשבת "חמה" יותר.
- `includeUrlPatterns` ו-`excludeUrlPatterns`: ביטויים רגולריים על הקישור, לסינון מדורים שאינם חדשות (ספורט, לייף סטייל, דעות). אם אין `include`, כל הקישורים נכנסים חוץ מה-`exclude`.
- `dateLabelIsLocalTime`: מסמנים `true` אם הפיד כותב "GMT" אבל בפועל נותן שעון ישראל (כך אצל וואלה ו-JPost). כדי לבדוק, משווים את זמן הפריט בפיד לזמן שמופיע בכתבה עצמה.
- כדי לכבות מקור זמנית: `"enabled": false`.

## איך זה עובד

1. **הורדה** (`src/feeds.js`): כל 3 דקות, בזה אחר זה, עם הפסקה של 1.5 שניות בין בקשות. נשלח User-Agent מזוהה ונכבדים `ETag` ו-`If-Modified-Since`. מקור שנכשל ממשיך לרוץ בלי להפריע לאחרים, השגיאה נרשמת ב-`data/errors.log`, והמקור מקבל השהיה הולכת וגדלה עד 30 דקות.
2. **סינון** (`src/filters.js`): ממומן, חידונים, הורוסקופים ומדורים שאינם חדשות.
3. **נרמול תאריכים** (`src/dates.js`): הכל ל-UTC. זמנים עתידיים מוחלפים בזמן ההורדה.
4. **ניקוי כותרת** (`src/text.js`): הסרת "בלעדי:", "| צפו", פיסוק ומירכאות. ראשי תיבות כמו צה"ל נשמרים.
5. **ייצוג סמנטי** (`src/embedder.js`): המודל `intfloat/multilingual-e5-small` בגרסת ONNX מכווצת (int8), דרך transformers.js.
6. **קיבוץ** (`src/events.js`): כותרת חדשה מצטרפת לאירוע קיים אם הדמיון הממוצע שלה לכתבות שבו עובר את הסף. כותרות שלא הצטרפו לשום אירוע מקובצות ביניהן בשיטת average-linkage, שמונעת "שרשור" של סיפורים לא קשורים. אשכול הופך לאירוע רק כשיש בו `minSources` אתרים שונים.
7. **מגבלת 10**: כשהרשימה מלאה, האירוע שזוהה ראשון יוצא. הוא ממשיך בשקט לספוג כתבות המשך, כדי שלא יחזור לרשימה כ"חדש".
8. **כותרת האירוע**: מבין הכותרות המייצגות ביותר (עם עדיפות לעברית), נבחרת הקצרה ביותר. אין סיכום שנוצר על ידי מודל.

המצב נשמר ב-`data/state.json`, כך שאחרי הפעלה מחדש זמני הזיהוי נשמרים.

## מקורות פעילים ומקורות שדולגו

פעילים: ynet (כולל מבזקים), ישראל היום, מעריב (כולל מבזקים), הארץ, TheMarker, גלובס, סרוגים, ערוץ 7. Jerusalem Post כבוי.

דולגו:
- **ערוץ 14**: כבוי. הפיד עובד ממחשב ביתי, אבל מחזיר 403 לשרתי GitHub שמהם הסריקה רצה.
- **וואלה**: כבוי. בפיד ובעמוד ה-RSS שלהם כתוב שהשימוש מותר לשימוש פרטי / לא מסחרי בלבד — לא מתאים לאפליקציה ציבורית בלי אישור.
- **N12 (mako)**: חוסם גישה אוטומטית ואין לו RSS.
- **כאן 11**: מחזיר 403 ואין לו RSS.
- **Times of Israel**: ה-`robots.txt` שלו אוסר גישה ל-`/feed/`.

## מגבלות ידועות

- **עברית מול אנגלית (JPost):** התאמה בין שפות פחות אמינה. כ-50% מהזוגות נכונים, מתוך מדגם קטן של 10. הסף שם שמרני, ולכן JPost מצטרף לאירועים לעתים רחוקות.
- **אותה פרשה, התפתחות אחרת:** למשל "נתניהו מאשים את רונן בר" ו"רונן בר מגיש תביעת דיבה" יכולים להתאחד לאירוע אחד.
- **הסף מכויל על מדגם של יום אחד** (102 זוגות מתויגים). אם יופיעו מיזוגים שגויים, מעלים ל-0.90. אם אירועים מתפצלים, מורידים ל-0.88.
